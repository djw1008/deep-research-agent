## 已知限制

- 每题只有一个样本，无法估计模型随机性造成的题内方差。
- 显著性检验的样本量为 15，统计功效有限；“未检测到显著差异”不等于两者完全相同。
- Red/Judge 与被评系统共享模型家族时可能存在自评偏差。
- 本轮没有有效 RAGAS 数值，因此不报告 RAGAS 结论。
- Token 数为 API 真实用量；旧的字符估算值仅用于对照，不能替代计费用量。
- 完成率不代表结论事实正确，重要报告仍须人工核验引用来源。
